## Scope and acceptance

Specify separate default-off foreground app and granted exact-host opt-ins, local aggregation without browser/site double count, idleness/lock/sleep/revocation/disable boundaries, retention and deletion.

- [ ] Review synthetic timelines with boundary and overlap cases, Off/Empty/Revoked states, and deleted totals. No collector, real data, new access, or runtime integration.
- [ ] Use `docs/design/desktop-redesign/fixtures/screen-time.json`. Record expected versus observed outcomes for every row in the D2 matrix.
- [ ] Record reviewed base, commit/tree, OS/browser, command output, screenshots or GIF and hashes. Stop for explicit publication approval; scope and procedure in [packet 00](README.md).

### D2 expected state matrix

| Case | Expected outcome |
| --- | --- |
| Off | Both opt-ins default off; collect neither stream. |
| Enabled, empty | Show no recorded time, distinct from Off or Revoked. |
| Populated, overlapping browser and site | Attribute eligible activity without counting the same interval twice in combined totals. |
| Exact-host grant | Count only the granted host, not ungranted siblings or subdomains. |
| Idle, lock and sleep | Exclude time across each inactive boundary. |
| Revoked | Stop counting the affected host at revocation; report revoked access, not empty. |
| Disabled | Stop counting the disabled stream at the boundary without enabling or disabling the other stream. |
| Retention expiry and deletion | Exclude expired and deleted data from subsequent totals. |
