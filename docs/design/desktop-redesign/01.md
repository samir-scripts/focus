## Scope and acceptance

Wire the fourteen approved palette/mode maps verbatim from [palette.json](palette.json). Keep System and independent persisted slots; preserve valid stored IDs and fall back to Sage per slot for new profiles and missing or invalid IDs. Show canvas, rail, ink, accent and secondary in that order within every option and show the selected palette's swatches in the closed trigger. Hover and keyboard focus do not recolor the shell or save a palette; click, Enter or Space commits the option to its mode's slot. Apply it to the shell only when that mode is active.

- [ ] Select each option in both modes; compare actual colors, independent slots after reload, Sage fallback and System changes. Check arrows move visible focus without committing; Escape dismisses without changes and restores focus to the trigger. Do not change shell texture.
- [ ] Write an affected behavior test red first, implement, then run the required gates and capture the native surface against the frozen replay.
- [ ] Record reviewed base, commit/tree, OS/browser, command output, screenshots or GIF and hashes. Stop for explicit publication approval; scope and procedure in [packet 00](README.md).
